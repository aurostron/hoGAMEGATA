# Global Agent Rules (OpenCode & Antigravity)

## Documenting Changes
- **Rule**: Every change you make to any file MUST be appended to walkthrough.md — files modified, rationale, verification results. Additive only; never rewrite past entries.
- **Additive**: Updates to `walkthrough.md` must be additive—append new entries without overwriting previous logs.
- **Details**: Record a summary of files modified, design decisions/rationale, and verification results.
