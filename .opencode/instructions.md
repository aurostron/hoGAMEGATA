# OpenCode Instructions: Document Changes in Walkthrough

Every change you make to any file MUST be appended to walkthrough.md — files modified, rationale, verification results. Additive only; never rewrite past entries.

1. **Document in Walkthrough**: Record all changes in `walkthrough.md` (or a similarly named document such as `WALKTHROUGH.md`).
2. **Additive Updates**: Keep documentation **additive** by appending new change entries to the existing document rather than overwriting past entries.
3. **Log Content**: Include the date/timestamp or turn summary, files modified, purpose of changes, design rationale, and verification results.
