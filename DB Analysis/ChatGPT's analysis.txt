# My recommendation for hoGAMEGATA v1.0

I would prioritize these tasks in order:

1. **Add proper indexes** on every field used for sorting and filtering.
2. **Stop selecting every column**—create lightweight queries for lists and cards.
3. **Audit every query** that reads ~37,000 rows and ensure it uses `LIMIT` and can leverage an index.
4. **Introduce SQLite FTS5** for title search instead of `LIKE '%term%'`.
5. **Cache expensive queries** (Trending, New Releases, Highest Rated, For You defaults) in memory or on Cloudflare for several minutes to an hour.
6. **Run `EXPLAIN QUERY PLAN`** on your slowest queries. This will tell you exactly whether SQLite is using an index or performing a full table scan.
7. **Consider migrating to Cloudflare D1** after the query optimizations. D1's generous free tier is attractive, but migrating before fixing inefficient queries will only postpone the same problem.
