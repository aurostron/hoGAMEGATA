## 🎥 Screen Recording Instructions

1. **Open `promo/index.html`** directly in Chrome, Edge, or Brave (or run `npx serve promo`).
2. Press **`F`** to toggle **Fullscreen Mode**.
3. Press **`M`** or click **"Enable Sound"** to trigger the ambient cinematic synth soundtrack.
4. Press **`Space`** to start/pause the automated 5-scene promotional sequence.
5. Record your screen using OBS Studio, GeForce Experience, or Xbox Game Bar (`Win + Alt + R`).

### ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| **`Space`** | Play / Pause the Automated Cinematic Promo Reel |
| **`F`** | Toggle Fullscreen Mode |
| **`M`** | Toggle Ambient Web Audio Synthesizer (Music & Chimes) |
| **`Arrow Right` / `Arrow Left`** | Next / Previous Scene |
| **`1` - `5`** | Jump directly to Scene 1, 2, 3, 4, or 5 |
