# Claude Code Instructions

## Change-Log Rule
Every change you make to any file MUST be appended to walkthrough.md — files modified, rationale, verification results. Additive only; never rewrite past entries.

## Details
- When modifying code, configuration, or documentation files, record the changes at the bottom of `walkthrough.md`.
- Include files modified, design decisions / rationale, and verification results.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
